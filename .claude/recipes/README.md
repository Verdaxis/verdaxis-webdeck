# Slide Development Recipes

Token-efficient reference for building slides in verdaxis-webdeck. Read the recipe before writing code -- don't rediscover patterns.

## Recipes

| Recipe | When to use |
|--------|-------------|
| [new-slide.md](./new-slide.md) | Adding a new slide to the VC deck |
| [new-branch.md](./new-branch.md) | Adding a branch overlay (modal deep-dive) to an existing slide |

## Patterns

Slide archetypes with copy-paste skeletons. Read these when deciding how to structure a specific slide.

| Pattern | When to use |
|---------|-------------|
| [patterns/title-hero.md](./patterns/title-hero.md) | Opening/hero slides with dramatic visuals (ticker, typing, glow effects) |
| [patterns/data-cards.md](./patterns/data-cards.md) | Metrics, market sizing, stat cards with animated counters and concentric visuals |
| [patterns/feature-grid.md](./patterns/feature-grid.md) | Feature pillars, solution cards, icon-driven grid layouts |
